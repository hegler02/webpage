Mirinaeman Coding

Mirinaeman’s Coding is the body of the message

질문과 답변으로 자신의 판단을 세우고, 메시지를 PRD와 작동하는 웹앱으로 만듭니다.

공개 준비 중입니다. 공개 설치가 확인되면 설치 링크를 제공합니다.

내 판단이 앱이 되는 과정

  1. 만들고 싶은 앱과 실제로 겪는 불편을 설명합니다.
  2. AI의 제안과 대안을 비교하고 기능·디자인·데이터·비용을 직접 결정합니다.
  3. PRD와 수정 계획을 승인하면 AI가 구현하고 검증합니다.
  4. 본인의 계정으로 배포하고 실제 로그인·저장 등 필요한 경로를 확인합니다.
  5. 문제와 해결의 교훈을 최소한의 CQI로 남겨 다음 제작에 활용합니다.

시작 전에 준비할 것

  • 스킬을 실행할 수 있는 AI 환경과 코드 실행·파일 접근 권한
  • 배포할 때 본인의 GitHub·Vercel 계정, 인증이 필요하면 Supabase 계정
  • 외부 API가 필요할 때 본인의 API 키와 이용 한도

스킬은 무료입니다. AI 환경·호스팅·인증·API 등 외부 서비스 비용은 각 제공자의 요금과 본인의 사용량에 따릅니다.

한 테스트 계정에서 배포·가입·로그인·메모 저장·새로고침 재조회를 확인한 경험을 반영했습니다. 모든 앱의 성공을 보장하지 않습니다.
