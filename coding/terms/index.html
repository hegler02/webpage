제공 범위

이 스킬은 질문을 통한 기획과 판단, PRD 작성, 승인 범위의 코드 구현·검증·배포를 돕는 작업 지침입니다. 실행 가능한 도구와 계정 권한은 이용 환경에 따라 다릅니다.

판단과 구현

사용자는 목적·범위·데이터·비용·공개를 결정합니다. AI는 제안과 구현·검증을 맡습니다. 사람의 판단 책임이 AI 오류나 허위 검증을 정당화하지 않습니다.

비용과 결과

스킬 자체는 무료이며 외부 서비스 비용은 별도입니다. 생성 결과는 실제 환경에서 검토·시험해야 합니다. 아직 시험하지 않은 기능을 완료로 간주하지 않습니다.

공유와 업데이트

업데이트 이력은 이 페이지에서 확인합니다. 설치된 복사본의 자동 업데이트를 보장하지 않습니다. CQI 공유에는 별도의 동의와 검토가 필요합니다.
