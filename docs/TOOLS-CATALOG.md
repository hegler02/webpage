# 스킬·플러그인 관리

`tools/catalog/registry.json`이 단일 등록부입니다. 비밀·개인정보·동의 증빙은 넣지 않습니다.

1. items에 고유 slug, 고정 path, 이름, 종류, 분야, 버전, 소개, 사용 요건, 단계, 정책 버전과 개선 이력을 추가합니다.
2. 초기 status는 preparing, install_url은 null입니다. 심사 제출 후 review, 공개 설치와 정책 승인 확인 후 public으로 변경합니다. 종료하면 retired로 바꾸고 설치 URL을 제거합니다.
3. 항목별 실제 개인정보 처리와 약관을 검토합니다. 각 항목의 pages에 지원·개인정보·약관 내용을 기록하며 코딩 스킬 정책을 그대로 적용하지 않습니다.
4. `python3 tools/catalog/render.py`로 생성하고 `python3 tools/release_gate.py`로 검증합니다.
5. 변경을 검토해 기존 Git→Vercel 경로로 배포한 뒤 공개 URL을 확인합니다.

공개 사이트에는 방문자 계정·관리자 화면·수집 폼을 추가하지 않았습니다. 소유자가 대화에서 변경을 요청하면 AI가 등록부와 출력물을 갱신합니다. 변경 이력은 검토된 비식별 요약만 게시합니다. 정책 초안은 공개 제출용 확정 정책이 아닙니다.

WHAT: 등록부는 사이트의 하위로서 스킬 안내 원본을 담당. HOW: 생성 → 정적 안내 페이지. WHERE: 공개 메타데이터 포함, 원자료·개인정보 제외. DEPTH: L1.
