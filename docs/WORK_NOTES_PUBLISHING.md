# 작품해설 썸네일 제작·발행

2026-10-29 사용자 승인 범위: 작품해설에 새로 만든 썸네일을 넣고 WebP 또는 JPEG로 최적화한다.
향후 아카이브 작품해설 발행에도 이 절차를 기본으로 적용한다.

## 내용과 이미지

1. 실제 작품과 해설을 읽고 핵심 장면·의미를 확인한다. 모르는 제작 경험을 만들어내지 않는다.
2. 내장 imagegen으로 해당 해설에 맞는 새 표지를 제작한다. 기존 사진·인물의 사실적 기록으로 오인시키지 않는다.
3. 16:9 구도, 작은 카드에서도 읽히는 주제, 가장자리 잘림을 고려한다. 제목은 HTML로 표시하고 이미지 안에 긴 글자를 넣지 않는다.
4. 생성 결과를 직접 보고 승인된 내용과 맞는지 확인한다. 원본과 프롬프트는 작업 자료에 보관한다.
5. 아래 도구로 1200×675와 600×338 WebP를 만든다. 큰 파일은 200 KiB, 작은 파일은 80 KiB 이하이며 확대하지 않는다.

```text
python tools/prepare_work_note_thumbnail.py <생성된-원본-경로> <설명적인-영문-slug>
```

## 연결 및 검증

`pages/profile/data/work-note-thumbnails.json`에 작품해설 URL, 두 이미지 URL, 실제 장면을 설명하는 한국어 alt, 생성 이미지 표시를 넣는다.
이 목록은 `site.manifest.json`의 `editorial_pages`와 정확히 일치해야 한다.
원본 작품 재생 주소와 해설 주소는 서로 다른 역할이므로 기존 목적지를 보존한다.

```text
python tools/render_archive.py
python tools/work_note_thumbnails.py
python tools/release_gate.py
git diff --check
```

렌더러는 실제 img src와 srcset, 크기, 지연 로딩, alt를 출력한다.
누락된 표지·alt, 잘못된 크기, 용량 초과, 재사용된 파일은 배포 검사에서 차단한다.
1440px·768px·390px와 사용자가 문제를 지적한 폭에서 실제 카드, 한글 제목 줄바꿈, 로딩을 확인한다.
배포 후 공개 페이지와 이미지가 정상 응답하는지, 배포 커밋이 이번 변경인지 확인한다.

이미지 생성은 발행 작업을 수행하는 에이전트가 내장 도구로 실행한다.
CI는 이미지를 자동으로 창작하지 않으며, 필수 산출물의 누락을 차단한다.
검색엔진에 발견 가능한 이미지 구조를 갖추는 것이며 실제 색인·노출을 보장하는 규칙은 아니다.

## 범위

기존 작품 아카이브 전체의 이미지 교체, 메뉴 개편, 임의의 미리내벌스 뒷이야기 작성·링크 추가는 이 규칙에 포함하지 않는다.
뒷이야기는 사용자가 실제 원고나 발행을 요청한 경우에만 별도로 다룬다.
