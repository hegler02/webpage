ND 필터로 움직임의 질감 바꾸기

같은 밝기에서도 노출시간에 따라 이동체의 잔상이 달라지는 원리를 구분한다.

Stewart Carroll / Drone Film Guide

그림에서 확인할 세 가지필터 선택을 움직임의 표현과 연결한다.

1또렷하게 멈춘 자전거

왼쪽에서는 자전거와 사람의 윤곽이 길과 난간처럼 선명하게 보인다. 움직이는 대상이 한순간에 멈춘 듯한 질감을 만드는 부분을 찾는다.

2이동체에만 남은 잔상

가운데는 자전거와 사람의 윤곽이 이어지지만 뒤쪽 길과 난간은 선명하다. 피사체의 움직임과 화면 전체의 흔들림을 구분하는 기준을 읽는다.

3어두운 필터의 역할

오른쪽 탁자 위의 어두운 원형 필터와 카메라를 본다. 유리를 통과하는 빛을 줄이는 도구와 결과 영상에서 원하는 잔상을 연결해 생각한다.

촬영 설계

촬영을 이렇게 설계한다

1

움직임 표현을 정한다

제작자는 ND의 역할을 입사광을 줄여 모션 블러에 필요한 셔터속도를 얻는 것으로 설명한다. 필터를 끼웠다는 사실만으로 영상의 움직임이 좋아지는 것은 아니라는 출발점이다.

2

노출시간을 비교한다

교육 적용에서는 같은 장면 밝기를 유지하면서 짧은 노출과 긴 노출의 잔상을 비교한다. 이동체의 선명도와 배경의 선명도가 함께 달라지는지 따로 확인해야 원인을 구별할 수 있다.

3

교육 적용 · 다른 질감도 남긴다

빠르고 또렷한 움직임을 의도한다면 짧은 노출도 대안이 된다. 자연스러운 잔상을 원하는 경우와 동작을 분절해 보이게 할 경우를 나누고 필터 강도는 그 뒤에 검토한다.

밝은 환경에서 ND 필터와 셔터속도, 모션 블러의 관계를 설명하는 제작자 튜토리얼이다.

원본 영상ND 필터로 움직임의 질감 바꾸기

1. 이동체 윤곽

원본 시연에서 움직이는 대상의 경계를 본다. 짧은 노출의 또렷함과 긴 노출의 연결감을 비교할 수 있는지 확인한다.

2. 배경의 선명도

고정된 길이나 건물의 경계를 살핀다. 피사체에만 남은 잔상인지 카메라 전체의 흔들림인지 판단할 기준을 찾는다.

3. 밝기와 움직임

비교 영상의 밝기와 잔상을 따로 관찰한다. 필터로 빛이 줄어드는 것과 노출시간을 바꾼 효과를 혼동하지 않는다.

제작진 설명 · 한국어 요약 번역

빛을 줄여 움직임의 흐림을 선택하다

01

필터의 역할

Stewart Carroll의 본문은 ND 필터가 카메라에 들어오는 빛을 줄여 모션 블러를 얻을 셔터속도를 사용할 수 있게 한다고 설명한다.

02

미공개 시연

구체적인 자전거 시연이나 필터 강도별 결과는 본문에 없다.

03

학습안 범위

현재 그림의 자전거 비교는 이 원리를 설명하는 가상 예시이며, 특정 노출시간을 모든 촬영의 정답으로 지정하지 않는다.

내가 직접 만들어 본다

같은 밝기와 같은 고정 시점에서 이동체의 속도가 줄면 잔상도 줄어, 흐림의 원인이 움직임임을 지시한다.

촬영용어
프롬프트 · Prompt네거티브 · Negative
  1. S01카메라가 난간 옆 길 위에 가만히 떠 있다.
  2. S02영상은 하나의 연속 쇼트다.
  3. S03화면에 드론 기체는 나오지 않는다.
  4. S04처음 10초 동안 자전거가 길을 따라 빠르게 달린다.
  5. S05자전거가 빠르기 때문에 바퀴와 몸에 잔상이 남는다.
  6. S06카메라는 움직이지 않으므로 난간과 길은 선명하다.
  7. S07그래서 흐린 것은 달리는 자전거뿐이다.
  8. S08다음 10초 동안 자전거가 점점 속도를 늦춘다.
  9. S09속도가 줄자 잔상이 짧아지고 윤곽이 또렷해진다.
  10. S10마지막 10초 동안 자전거가 길 한가운데 멈춘다.
  11. S11멈추자 자전거와 사람이 난간처럼 선명해진다.
  12. S12화면의 밝기는 처음부터 끝까지 변하지 않는다.
  13. S13그 결과 선명도 차이는 움직임에서만 생긴다.

  • 카메라가 자전거를 따라 같이 움직이는 것 금지
  • 영상 중간에 컷이 들어가 장면이 끊기는 것 금지
  • 화면에 드론 기체가 나타나는 것 금지
  • 자전거가 처음부터 느리게 굴러가는 것 금지
  • 바퀴와 몸이 오려 붙인 듯 선명한 것 금지
  • 난간과 길까지 함께 번져 흐려지는 것 금지
  • 화면 전체가 떨리듯 흔들리는 것 금지
  • 자전거가 갑자기 서거나 다시 빨라지는 것 금지
  • 속도가 줄어도 잔상이 같은 길이로 남는 것 금지
  • 자전거가 길 밖으로 벗어나 사라지는 것 금지
  • 멈춘 뒤에도 사람의 윤곽이 번져 있는 것 금지
  • 중간에 화면이 어두워지거나 밝아지는 것 금지
  • 밝기 변화가 선명도 차이의 원인처럼 보이는 것 금지

결과에서 볼 것

  • 달릴 때 자전거만 흐리고 난간과 길은 선명했는가
  • 속도가 줄면서 잔상이 짧아졌는가
  • 멈췄을 때 자전거가 난간만큼 선명했고 밝기는 같았는가

내 촬영에 적용할 때

교육 적용으로 밝기와 구도를 맞춘 짧은 비교 영상을 만든 뒤 자전거 바퀴, 몸체, 배경을 따로 살핀다.

원하는 잔상과 전체 화면 흔들림을 구별하고 장면의 속도감에 맞는 노출시간을 선택한다.

선정 이유 · 필터를 장비 목록이 아니라 움직임의 질감을 정하는 노출 선택으로 이해하는 사례다.
