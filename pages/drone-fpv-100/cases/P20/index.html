Burberry 2021: 패션쇼 공간을 통과하는 시선

계획한 동선의 성공과 우연한 응시 장면의 활용 가능성을 별도로 판단한다.

Solent Sky Services / Vivid Broadcast

그림에서 확인할 세 가지계획한 동선과 현장 반응의 활용을 구분한다.

1계획된 진행

가상 패션 공간에서 모델의 진행과 주변 계단·통로를 읽는다. 공간을 모두 통과하는 것보다 의상과 인물이 잘 보이는지 살핀다.

2카메라를 보는 모델

응시가 생긴 그림에서 관객과 모델의 관계가 어떻게 달라지는지 비교한다. 무심한 진행과 의도적인 대면의 차이를 말해 본다.

3모니터에서 보이는 선택

오른쪽 감독의 모니터와 왼쪽 아래 모델의 응시를 비교한다. 넓은 공간의 많은 요소 중 화면에 남은 얼굴과 의상이 무엇인지 살핀다.

촬영 설계

촬영을 이렇게 설계한다

1

현장 변화를 답사에 반영

교육 제안: 건물의 평면뿐 아니라 무대 장식·계단·모델 진행이 만드는 실제 화면을 확인한다. 빈 공간 투어의 경로를 그대로 가져오면 패션의 주목 대상이 빠질 수 있다.

2

감독과 같은 화면 공유

교육 제안: 경로를 완주하는 조종 판단과 장면을 채택하는 연출 판단의 기준을 나눈다. 감독이 결과 화면을 보며 무엇을 확인해야 하는지 촬영 전에 구체적으로 정한다.

3

예외 반응을 따로 평가

교육 제안: 모델의 응시가 생기면 계획 위반만으로 버리지 말고 장면의 분위기를 바꾸는지 본다. 다만 우연한 성공을 다음 촬영에서 반복 가능한 동선으로 보장하지 않는다.

Burberry 매장 패션쇼에서 감독에게 실시간 화면을 보내며 실내 촬영을 진행했다.

원본 영상Burberry 2021: 패션쇼 공간을 통과하는 시선

1. 시선의 효과

모델이 카메라를 보는 구간이 있다면 그 전후 시선의 차이를 관찰한다. 관객이 인물과 직접 마주하는 느낌이 어떤 순간에 생기는지 판단한다.

2. 공간과 인물의 비중

무대 구조가 강조되는 동안 의상과 인물 표정이 얼마나 읽히는지 본다. 공간을 지나는 움직임이 모델의 정보를 줄이지 않는지 확인한다.

3. 원작의 채택 결과

영상에서 응시 장면이 어떤 컷 사이에 놓였는지 확인한다. 제작기에서 채택 사실을 읽었다는 것과 직접 효과를 평가했다는 것을 구분한다.

  1. S01패션쇼 공간의 계단과 통로를 모델이 걷는다.
  2. S02영상은 하나의 연속 쇼트다.
  3. S03처음 10초 동안 드론은 모델 뒤를 따라 통로를 지난다.
  4. S04모델은 앞만 보고 걷는다.
  5. S05드론은 계획한 경로를 그대로 따른다.
  6. S06다음 10초 동안 모델이 걸음을 멈추고 고개를 돌린다.
  7. S07모델이 고개를 돌리자 카메라를 똑바로 바라본다.
  8. S08시선이 마주치기 때문에 장면의 분위기가 바뀐다.
  9. S09드론은 경로를 벗어나지 않고 모델 앞에서 속도를 줄인다.
  10. S10마지막 10초 동안 모델은 다시 앞을 보고 걷기 시작한다.
  11. S11드론은 남은 경로를 끝까지 지나간다.
  12. S12그 결과 경로 완주와 우연한 응시가 따로 읽힌다.

계획한 동선의 성공과 우연한 응시 장면의 활용 가능성을 별도로 판단한다.
