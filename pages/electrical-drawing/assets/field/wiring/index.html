오늘 추적할 신호

01　/　읽기

어느 도면을 펼칠까요?

현장 센서부터 PLC 입력까지, 기호와 기호 사이의 전선을 직접 따라갈 수 있는 도면을 고르세요.

도면을 선택하면 원도면이 열립니다.

처음 읽을 때 보는 힌트

INPUT은 PLC가 외부 상태를 받는 쪽입니다. 도면에서 의뢰서와 같은 영문 설명을 찾고, 그 기호에서 아래로 이어진 선을 손가락으로 따라가세요. 중간의 단자 번호와 맨 아래 입력 주소를 따로 읽습니다.

02　/　웹 배선판

두 구간을 직접 연결합니다

① 센서와 단자를 차례로 누르세요. ② 같은 단자를 다시 누르고 PLC 입력을 누르세요. 키보드는 Tab으로 이동하고 Enter로 선택합니다. 배선판은 연결 관계를 표현한 학습용 보기입니다.

    03　/　함 안에서 확인

    실제로 어느 단자에 들어갈까요?

    22번 주 제어반의 실제 단자대 일부입니다. 방금 연결한 입력 주소가 적힌 행을 찾고 같은 행의 단자 번호를 고르세요.

    배선 검사에 통과한 뒤 단자 번호를 고르세요.

    04　/　원도면 대조

    그린 선과 원도면을 비교하세요

    CAD에서 같은 선 그리기 ↓
    05　/　AutoCAD Electrical 2027

    프로젝트 사본에 다시 그리기

    웹에서 그린 한 가지 신호를 Windows 실습 PC의 DWG에서 재현합니다. 도면 이름, 기기 태그, 입력 주소는 기존 프로젝트 값을 사용합니다.

    1. 개인 작업 사본 준비. 실습 프로젝트 ZIP을 새로운 개인 폴더 IEC-입력실습에 전부 풀고, 프로젝트가 닫힌 상태에서 START-HERE.cmd를 실행합니다. 준비 완료 후 프로젝트 관리자에서 IEC-Training-2027.wdp를 활성화하고 09번 DWG를 엽니다. 2027 프로젝트와 실행 안내 ↗
    2. 작도 전 원도면 읽기. 선택한 센서의 설명이 있는 열을 찾습니다. 센서, 단자 번호, 해당 입력 주소와 현재 와이어 유형을 기록합니다. 이력 대조용으로 이 열을 캡처합니다.
    3. 두 구간 비우기. 사본의 09번에서 구조도 탭의 와이어 자르기 도구로 해당 열의 센서 하단과 단자 상단 사이, 단자 하단과 PLC 입력 사이의 선만 선택해 제거합니다. 센서·단자·PLC 심벌과 센서 위쪽의 공통 공급선은 그대로 둡니다. 잘못 고르면 즉시 실행 취소합니다.
    4. 회로 접속점에 배선. 구조도 탭에서 와이어 삽입(AEWIRE)을 시작하고 인접한 동일 회로 열의 와이어 유형을 확인해 맞춥니다. 첫 선은 센서 하단 접속점에서 단자 상단까지, 두 번째는 같은 단자 하단에서 해당 PLC 채널의 접속점까지 그립니다. 두 구간을 따로 끝내고 심벌의 접속점에 붙었는지 확대합니다.
    5. 속성 대조. 센서 태그, 단자대·단자 번호, 모듈 PLC1의 입력 주소를 확인합니다. 이 샘플의 해당 열에는 입력 주소와 같은 문자열이 와이어 번호로도 표시됩니다. 재배선 뒤 번호가 빠졌다면 해당 네트에 와이어 번호를 삽입·편집해 원도면 값과 맞춥니다. 22번은 Panel Layout 폴더의 별도 DWG입니다. 열어 같은 단자대 행의 번호와 와이어 표기를 대조합니다. 수정한 09번 DWG를 저장하고, 연결한 열과 22번 단자대 행을 함께 캡처해 과제 기록에 붙입니다.
    선이 닿아 보이는데 결과가 다를 때

    먼저 선 양 끝이 기호의 접속점에 붙었는지 확대하세요. 단자 번호 11과 입력 끝자리 00처럼 서로 다른 표기가 한 회로에 들어갈 수 있습니다. 다음 열과 섞였는지 원도면을 대조하고, 잘못 그린 구간만 지워 다시 배선합니다.
