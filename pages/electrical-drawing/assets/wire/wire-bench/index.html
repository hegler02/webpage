11강 / 와이어 번호 실험실

같은 선인데 왜 번호가 다를까요?

아래 네 단계의 선택이 번호에 어떤 영향을 주는지 시험합니다. 이 화면은 연습용 모형입니다. 실습 회로의 도면층과 결과를 사용하며, 네 연결망의 처리 순서를 왼쪽부터 고정했습니다.

처음이라면 · 연결망부터 읽기

전기적으로 이어진 선들의 묶음을 연결망이라고 합니다. 이 모형에서는 가로줄 하나가 전원 한 상입니다. A·B·C·D의 네 칸은 서로 떨어진 네 연결망입니다. 각 칸 안에서 끝점이 맞닿는 두 선 조각은 같은 연결망입니다. 선 조각 수와 붙는 번호 수를 비교하세요.

1. 사용할 도면층을 와이어 유형으로 등록하세요

세 도면층을 모두 선택합니다. 같은 이름의 도면층이 있어도 와이어 유형 표에 등록되어야 Electrical이 배선을 인식합니다. 이 모형의 WIRES는 이미 등록된 일반 와이어 유형입니다.

2. 선을 어느 도면층으로 보낼까요?

지금 선은 모두 일반 도면층 0에 있습니다. R상은 RED-2.5SQ, S상은 BLU-2.5SQ, T상은 GRN-2.5SQ를 고르세요. 한 줄의 선택은 그 상에 속하는 A~D 네 연결망에 적용됩니다.

3. 프로젝트에서 도면층별 규칙을 준비하세요

R상에는 R%N, S상에는 S%N, T상에는 T%N을 사용합니다. %N 자리에 순번이 들어갑니다. 각 유형의 시작값은 1로 입력합니다. 이번 모형의 순번은 1씩 증가합니다. 각 행에는 도면층별 형식과 시작값을 넣고, 실제 CAD에서 기본 순번 증분은 도면의 순차 번호 설정을 확인하세요.

4. 번호를 붙여 결과를 비교하세요

프로젝트에 규칙을 저장한 다음, 번호 부여 명령의 실행 창에서도 이번에 그 규칙을 사용할지 선택합니다. 먼저 아래 항목을 끈 채로 계산한 뒤 켜고 다시 계산해 숫자를 비교하세요.

아직 번호를 부여하지 않았습니다.

각 상의 결과 · 번호가 바뀌면 이전 값도 함께 표시합니다.
상A · 주간선 왼쪽B · 주간선 오른쪽C · 왼쪽 분기 아래D · 오른쪽 분기 아래

칸마다 맞닿는 두 선에 번호 하나가 붙습니다. 등록되지 않은 층의 연결망에는 ‘번호 없음’이 표시됩니다. 이 표는 실습 회로의 네 위치를 분리해 보여줍니다.

고정 번호도 같이 바뀔까요?

번호가 생긴 뒤 선택하세요. 빨간 도면층의 시작값을 10으로 바꿔 재계산합니다. A의 고정 번호는 유지되고 B~D에 새 순번이 붙습니다. 고정을 풀고 재계산한 뒤 다시 비교하세요.

막힌 곳을 찾아 복구하기
  1. 모두 ‘번호 없음’이면 1단계 등록과 2단계 선의 도면층을 함께 봅니다. 도면층 0은 이 모형에 등록되어 있지 않습니다.
  2. 숫자만 붙으면 프로젝트에서 규칙을 사용할지 지정했는지, 실행 창에서 ‘와이어 도면층 형식 재지정 사용’을 선택했는지 두 곳을 확인합니다. 선의 도면층이 WIRES인지, 원하는 도면층인지도 보세요.
  3. S상에 R 번호가 붙으면 실제로 선택한 도면층과 그 도면층에 입력한 접두 문자를 각각 확인합니다.
  4. 값을 고쳐도 이전 결과가 보이면 ‘번호 부여 · 다시 계산’을 누릅니다. 이미 고정한 번호가 있는지도 봅니다.

웹 연습 다음 / 개인 프로젝트에서 재현

본인 DWG에서 같은 조건을 만듭니다

시작 도면 DXF 받기 ↓

  1. DXF를 열어 쓰기 가능한 개인 실습 폴더에 wire-type-practice.dwg로 저장합니다. 프로젝트 관리자에서 개인 프로젝트를 활성화하고 저장한 DWG를 프로젝트에 추가해 엽니다.
  2. A~D 칸의 가로줄은 일반 LINE입니다. 속성에서 도면층 0을 확인합니다. 문자·구역 표시는 LAB_NOTE에 있습니다. 이 안내용 도면층은 일반 도면층으로 둡니다.
  3. 와이어 유형 작성/편집에서 교안의 세 도면층을 와이어 유형으로 등록합니다. 와이어 번호 사용 여부와 기본 유형을 확인합니다. 각 행의 선분만 선택하여 해당 와이어 유형의 도면층으로 바꾸고 속성에서 확인하세요.
  4. 프로젝트 특성 → 와이어 번호에서 와이어 도면층 기반 설정을 켭니다. 설정 표에 세 도면층 이름과 해당 번호 형식, 순차 시작값 1을 입력합니다. 도면 특성의 와이어 번호에서 순차 방식과 기본 증분을 확인합니다. 와이어 번호 삽입(AEWIRENO)을 실행한 뒤 실행 창에서 ‘와이어 도면층 형식 재지정 사용’을 선택하고, 연습 도면 전체의 번호를 부여합니다.
  5. 서로 만나는 두 조각에는 번호가 하나인지, 떨어진 칸은 다른 번호인지 확인합니다. 처리 순서에 따라 CAD의 개별 위치 순번은 달라질 수 있습니다. 실제 도면의 처리 순서·고정 번호와 이번 실습판 조건을 먼저 대조하세요.

남길 것　수정한 DWG, 와이어 유형 표와 도면층별 규칙의 캡처, 번호가 들어간 도면, 예상과 다를 때 수정한 설정 한 줄.
