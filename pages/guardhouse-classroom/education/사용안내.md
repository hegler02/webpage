# 경비실 교육용 샘플 1

학습실 주소: https://mirinaeman.com/pages/guardhouse-classroom/

## 처음 시작할 때

1. **시작하기**에서 ‘첫 수업 시작’을 누릅니다.
2. **도면과 건물**에서 평면도·단면도·입면도를 바꿔 봅니다. 창문을 누르면 같은 대상이 두 화면에서 강조됩니다. 오른쪽에 실제 모델의 치수와 연결 도면이 나타납니다.
3. **구조와 철근**에서 지붕판·바닥판·벽·기초를 선택합니다. ‘이 부재 계산’을 누르면 해당 계산서로 이동합니다.
4. **전기설계**에서 조명·스위치·콘센트·분전반을 살펴봅니다. 조명을 선택해 소비전력과 방 안의 위치를 바꾸면 도면·3D·배선 길이·회로 계산에 함께 반영됩니다.
5. **계산과 확인**에서 단위와 식을 읽고, 지붕 활하중을 바꾸어 결과를 비교합니다. 비교 실험은 기본 설계를 덮어쓰지 않습니다.
6. **실감 체험**에서 ‘실내 둘러보기’를 누릅니다. W·A·S·D 또는 방향키로 이동하고, 마우스 드래그로 둘러봅니다. ‘스위치 앞으로’로 이동한 다음 벽의 스위치를 직접 누르거나 E 키를 누르면 조명을 조작합니다. 화면의 이동 버튼도 사용할 수 있습니다.

모르는 말은 **용어사전**에서 검색합니다. ‘모델에서 위치 보기’는 해당 도면과 부재를 바로 엽니다. **전체 건물로**를 누르면 부분 보기와 분해를 해제합니다.

## 바닥 아래·재료·소방을 더 살펴보기

- **기초·PIT 보기**: 전체 건물 옆 버튼으로 바로 엽니다. PIT는 화장실·탕비실 아래의 빈 공간이며 기초 전체를 뜻하지 않습니다. 내부 4,150 × 1,850 mm, 판 아래 높이 850 mm, 점검구 600 × 600 mm입니다. ‘PIT 단면’은 앞벽을 걷어내고, 덮개는 들어 올려 위치를 보여줍니다.
- **구조와 철근**: 부재를 누르면 해당 부재가 확대됩니다. ‘콘크리트 / 철근 / 겹쳐 보기’를 눌러 같은 부재의 차이를 비교합니다.
- **재료와 외관**: 미장·벽돌 타일·석재 패널을 적용합니다. ‘구성층 펼쳐보기’에서 1,200 × 2,000 mm 대표 조각의 외장 20, 바탕 10, 단열 70, 콘크리트 200, 실내 마감 15 mm를 선택합니다. 건물 외장 영역 100 mm 안을 나눈 교육용 구성입니다. 전체 외벽이 개별 구성층 솔리드로 다시 생성되는 기능은 아니며, GLB에는 구성 정보를 속성으로 포함합니다.
- **소방설계**: F-101 배치도와 F-102 신호·전원 원리도를 비교합니다. 감지기·발신기 시험 → 수신 표시 → 경보 점등 → 복구를 실습합니다. 일반 전원을 끄면 기존 조명이 소등되고, 예비전원이 있으면 유도등과 비상조명이 켜집니다. 경보는 시각적인 상태 변화로 표시합니다.
- **안전점검**: 소방·피난·전기·건축·구조·재료 10개 항목에서 ‘해당 위치·도면 보기’를 누릅니다. 결과와 메모는 즉시 저장됩니다. ‘살펴봄’은 학습 기록이며 안전·준공 합격 판정이 아닙니다.
- **실내 휠**: 눈높이와 발 위치를 유지하면서 시야각 40~90°를 바꿉니다. 실제 이동은 W·A·S·D 또는 이동 버튼입니다. ‘기본 시야’는 68°로 복원합니다.

외장 표면만으로 불연·준불연 여부를 판단하지 않습니다. 제품·단열재·접착재·전체 구성의 시험·인정 자료를 함께 보는 방법을 배웁니다. 소방은 장치의 역할과 전원·신호 원리 학습이며 법정 설치대상, 배선 규격·종단저항, 배터리 용량·지속시간 산정, 스프링클러·소화전 설계는 포함하지 않습니다.

## 실습 저장과 복원

기구의 소비전력·조명 위치·스위치·차단기·학습 표시는 현재 브라우저에 저장됩니다. 선택한 기구의 ‘이 기구 복원’ 또는 상단 ‘실습 초기화’로 기본 예제로 돌아갈 수 있습니다. 전체 계산 결과는 ‘현재 계산 데이터 저장’에서 내보냅니다.

외관 선택·소방 시험 상태·예비전원·점검 기록도 저장됩니다. 전체 초기화는 이 기록까지 되돌립니다. 여러 탭이 열려 있다면 사용할 탭을 새로고침하여 최신 화면으로 수업을 진행하세요.

## ZIP 구성

- `architecture-R4.zip`: 기본 건축 수정도면 DWG·DXF 10장과 R4 자료.
- `A-101.svg`~`A-110.svg`: 현재 샘플의 건축 학습 도면.
- `S-101`, `S-102`: 지붕·바닥 및 벽·기초 배근도. SVG·DWG·DXF.
- `E-101`~`E-103`: 조명, 콘센트·전원, 분전반 회로도. SVG·DWG·DXF. 추가한 근무용 가구는 전기 배치도에도 표시했습니다.
- `F-101`, `F-102`: 소방기구·피난 배치와 화재신호·비상전원 원리도. SVG·DWG·DXF. 신호 원리도는 단자 결선도와 구분합니다.
- `M-101`: 외벽 재료 구성 개념도. SVG·DWG·DXF. 얇은 층을 읽도록 가로 비례를 일부 확대했습니다.
- `sample-1-full.glb`, `sample-1-open.glb`: 건축·직선 철근·전기기구·전선관 3D 모델. GLB 길이 단위는 m입니다.
- `calculation-book.html`: 기본 예제 계산서. 같은 폴더의 `classroom.css`와 함께 엽니다.
- `sample-1.json`: 도면·모델·회로·배근·계산에 사용한 연결 데이터.

두 GLB에 소방기구 9개를 추가했고, JSON에는 소방·재료·점검 항목과 참고 출처도 포함합니다. 기본 예제 자료는 학습 도면 18장, 새 편집 도면 8장입니다.

SVG 학습 도면과 GLB는 추가 가구를 포함한 현재 샘플입니다. 건축 R4 파일은 기본 건축 설계 자료로 함께 제공합니다. DWG·DXF 길이 단위는 mm입니다.

구조 계산은 대표 부재의 수직하중·휨·평균 응력·지반 압력을 배우는 모형입니다. 배근은 직선 철근의 위치·간격·피복을 학습하며 정착·이음·개구부 보강 가공 상세는 포함하지 않습니다. 조건과 식은 계산서에 모았습니다. 실내 빛은 회로와 연결한 시각화이며 조도 계산 결과가 아닙니다.

이 버전은 경비실 교육용 샘플 1입니다. 추가 도면은 검토한 뒤 교육 샘플로 늘리며, 임의 DWG 자동 변환은 이번 버전의 기능에 포함하지 않습니다.
