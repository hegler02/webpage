# 서울 상공 — 승인된 A안의 웹 표현

사용자가 선택한 실제 영상 A의 타이포와 색을 그대로 이어가는 프로젝트 디자인이다.
외부 DESIGN.md를 승인받았다고 주장하지 않는다.

- 주 제목: Black Han Sans 400. 문장의 질량과 단정적인 판단.
- 영문 보조: Teko 500. 드론 작전과 고층 건물의 수직성.
- 읽기: Pretendard 400/600. 긴 한국어 원문과 검토 문장은 꾸미지 않고 읽힌다.
- 어두운 강철 바탕 #0b141c, 밝은 글자 #e5edf1, 보조 #b5c3cd, 강조 #daa15f.
- 화면 전체 장면과 큰 타이틀을 우선한다. 둥근 카드·장식 대시보드·글리치·랜덤 입자는 사용하지 않는다.
- 본문 18px/1.8. 제목 leading 1.24, tracking -0.025em. Hero 1.16/-0.025em.
- 폭 390/768/1440에 맞는 단일 breakpoints 700/1100. 모바일은 장면과 문장 세로 재배치.
- 상단에 감상/연출노트/페이지 공유. 타이틀 아래 41초 영상 감상을 분명히 제안한다.
- 인과 섹션은 큰 스틸과 원인→행동→결과의 문장을 잇는다. 읽을 문장은 JS 없이 모두 보인다.
- motion: 스크롤 시 장면 교차 전환 450ms. reduced-motion에서 즉시 전환하며 sticky 해제.
- 원본 영상과 원문은 사실 자료다. 도시 실루엣 및 일부 충돌 인과의 한계를 숨기지 않는다.
