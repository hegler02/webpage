# 공포의 선풍기 공개 등록

사용자 승인: “배포하고 mirinaeman.com에 올려”.

| 대상 | Before | After |
|---|---|---|
| 비교 감상실 | 소유자 전용 | 전체 공개, 기존 주소 유지 |
| 아카이브·홈·별자리 | 미등록 | 공식 카탈로그 export로 등록, 대표 썸네일·설명 |
| 소개 | 없음 | 기존 소개 페이지 디자인으로 작품·감상법·관련 작품 제공 |

[4-Point] render_fan_intro.py — WHAT: 아카이브의 하위로 작품 소개 담당 | HOW: 렌더링 | WHERE: 공식 카탈로그·현재 작품 맥락 포함, Work 메뉴·시네마 구현 제외 | DEPTH: L2

검증: release-check.txt, browser-check.txt. 공개 Site 자동 HTTP 검사 403; 플랫폼 전체 공개 및 성공 배포는 확인했으며 일반 방문자 차단으로 단정하지 않는다. mirinaeman.com 소개·카탈로그 공개 HTTP 검증은 배포 후 수행한다.

별도 중앙 스킬 저장은 HTTP 500, 성공한 원격 재조회에서 신규 기록 부재 확인. 재현 가능한 공식 export와 원장 입력을 이 저장소에 보존했다. 중앙 스킬 저장 완료로 보고하지 않는다. 기존공개내일을위해 메타데이터를 복원한 공식 export여서 이전 63작품의 공개 필드는 변경되지 않았다.
