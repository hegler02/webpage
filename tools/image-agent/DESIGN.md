# 단문 인과체인 · 이미지 작업실

19장 강의의 원문은 읽기 모드에 보존한다. 발표는 68개의 상태로 나누며 한 단계는 한 문장과 그 문장이 지정하는 장면 변화를 연결한다.

밝은 편집실 시안이 이번 구현의 시각 기준이다. Lottielab 참조를 검토했으나 원본 디자인 시스템의 동일 복제 또는 corpus-lock 검증 완료를 주장하지 않는다. 한글은 승인된 Pretendard를 사용한다. 명암 대비와 한글 줄간격은 실제 강의 화면에서 검증한다.

- WHAT: 이미지 하네스 강의의 하위로서 단문과 장면의 관계를 설명한다.
- HOW: 연결한다 → 수정 가능한 장면.
- WHERE: ImageAgent 강의 본문과 전용 SVG 도식. 다른 강의, 실제 이미지 생성 서비스, 커서 장식, 음원은 제외한다.
- DEPTH: 내용 L1, 발표 상태 L2, 애니메이션 L3.

## 관계의 구분

대상 → 속성은 의존 관계다. 조건 → 결과는 인과 관계다. 둘을 무조건 물리적 원인·결과로 설명하지 않는다. 안경의 세부 조건은 동일한 대상의 정체성을 유지한다. 비 → 젖은 도로 → 간판 반사는 앞 결과가 다음 조건이 되는 사례다.

## 동작 소유권

content.py가 문장·결과·관계의 정본이다. illustrations.py는 명명된 SVG 그룹을 만든다. state.js는 장면·단계 전이만 담당한다. deck.js는 조작과 정지 상태를 렌더링한다. motion.js는 GSAP·Flip을 통해 그 사이의 일시적 스타일과 viewBox를 보간한다. 역이동·빠른 이동·모션 중단 뒤에는 정지 상태로 정리한다.

## 디자인 검증 범위

공용 validate_static_site.py의 기본 경로는 어두운 기본 테마와 라이트 재매핑을 모두 요구한다. 이 프로젝트는 승인된 단일 밝은 시안이므로 그 두 정책 항목은 맞지 않는다. 검증기를 수정하거나 가짜 다크 테마를 넣지 않는다. 전체 정적 게이트 PASS를 주장하지 않는다. 콘텐츠·폰트·연결·공유 메타데이터 검사와 실제 밝은 화면의 대비·조작·레이아웃 검증을 별도로 기록한다.

## 재현

python3 tools/image-agent/render.py
python3 tools/image-agent/assets.py
python3 tools/image-agent/validate.py
