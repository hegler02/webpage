# Suno로 원하는 노래 만들기 — DESIGN

## 메시지와 권위
개인의 이야기와 메시지를 가사·장르·보컬·프롬프트로 설계하고 작품으로 발표한다.
17장과 한·영 전환을 보존한다. 사용자 승인: 제안된 Before/After 표에 대해 “가자”.
원본: a369e97d46ce043797c58c0e009f2b32b9821868의 pages/sono_slide/index.html.
표현 권위: 기존 강의의 black/amber/mint와 사용자가 승인한 이번 수정안.
제주 발표본의 레이아웃·단일 이동 상태·취소 가능한 전환을 재사용하되 독립 파일로 고정한다.
제주 발표본에 대한 “존나 멋진데?”는 그 작품에 대한 반응이다. 이번 결과의 수락으로 대체하지 않는다.

## 무대와 타이포
styles.css :root가 1920×1080 무대, 104px 바깥 여백, 316px 제목 영역,
480px 본문, 32px 간격의 정본이다. 모든 화면에서 무대 전체를 균일 배율로 축소한다.
휴대폰에서는 조작부만 작아지고 슬라이드 좌표·비율은 유지된다. 읽기 모드는 JS 미실행 시 제공한다.
글꼴: Pretendard(SIL OFL)를 강의 전체 문자로 서브셋한 Mirinae Music Sans.
예약 이름을 바꾸고 원본/파생 해시와 라이선스를 assets에 기록했다.
한국어·영어의 제목 역할 크기는 명시적으로 분리한다. 자간/행간을 장면별로 임의 축소하지 않는다.
패널의 설명 영역은 공통 3행 예산, 앨범 제목은 공통 2행 예산을 갖는다.

## 장면 관계
1–4: 원래 작품 이미지에서 개인의 음악으로 시선을 옮기며 Public/Private 비교를 동시에 드러낸다.
5–12: 앰버 PART 선언 후 가사·장르·보컬·목적을 구분한다. 가사 구조와 프롬프트 층은 순서대로 드러난다.
13–17: 제작 흐름 → 실제 작품 진열 → 설계 파트너 → 실습 문장 → 마지막 선언.
motion.js timing이 전환 시간의 정본이다. 장면 이동 상태는 presentation.js만 소유한다.
효과음·자동 장면 재생·마우스 추적 효과를 추가하지 않는다.

## 미디어
원본 Suno 화면 3개와 Sound Design Lab V2 화면 1개를 최적화해 자체 호스팅한다.
네 작품은 기존 아카이브의 실제 대표 이미지를 사용하며 전체 비율을 보존한다.
원본 배경 MP4는 403, 실습 스크린샷은 525로 확보하지 못했다. 외부 우회 없이
첫 화면은 실제 작품 이미지, 실습은 작성할 문장과 후렴 과제로 구성한다.
화면 예시는 제작 당시 자료임을 표시하고 V2를 현재 최신 제품이라고 주장하지 않는다.

## 승인된 두 번째 표현 — Record Sleeve
사용자 피드백: “약간 아까 코딩쪽하고 패턴이 비슷해서 좀 식상하긴 하다. 조금 다른 형태로는 안되니? 레이아웃은 좋다”.
Before/After 제안(재킷, SIDE 속지, 펼침면, 편곡 트랙, 제작 시트, 작품 선반)을 제시한 뒤
“그래 좋아 가보자”로 구현 승인을 받았다. 레이아웃에 대한 수용과 새 표현의 최종 수용은 구분한다.

이 버전의 표현 권위는 사용자가 승인한 위 제안이다. 다른 코퍼스의 토큰을 섞지 않았다.
1920×1080, 바깥 여백, 제목·본문 높이와 정렬 기준선은 이전 버전 그대로다.
색은 기존 검정·앰버에 크림색 속지와 진한 초록 재킷을 대응시킨다.
한국어 제목은 기존 Mirinae Music Sans의 보통/굵은 대비, 영문 장식 글자와 순번은
CSS --latin-serif(Georgia, Times New Roman, serif) 계열을 사용한다. 추가 웹폰트 요청은 없다.
시스템 세리프의 플랫폼별 미세한 차이는 허용하며 고정된 한글 본문의 가독성과 분리한다.

편곡 트랙의 선은 구간 구조를 나타내는 도식이다. 실제 음원의 파형이나 시간을 뜻하지 않는다.
전환은 WAAPI만 사용한다. timing/distance는 motion.js의 단일 정의다.
이전 타이머/애니메이션은 새 입력에서 취소되고, 축소 모션에서는 모든 내용을 즉시 표시한다.
기존 HTML 콘텐츠·링크·17장·한영 언어·URL을 보존한다. 읽기 모드는 고정 무대를 사용하지 않아
JS가 없는 1000px 문서에서도 재킷이 잘리지 않도록 흐름 배치를 적용한다.
